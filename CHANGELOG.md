# Changelog

## 1.0.0 — 2026-10-20

Initial named release, based on the user-validated Test 2 build.
- Independent vanilla models for supported mob ragdolls.
- Original Minecraft base textures during ragdoll rendering.
- Normal Fresh Animations retained for living and recovered mobs.
- Mob-only integration; no player-ragdoll hooks.
- Embedded user-supplied icon, source package and credits.

Known issue: a brief visible transition entering/leaving ragdoll remains.
